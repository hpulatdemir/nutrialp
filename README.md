# NutriAlp

Alp'in bağırsak ormanı macerasını anlatan sesli video ve kişisel site.

## İçerik

- `index.html` — sitenin ana sayfası (videoyu oynatır)
- `nutrialp-sesli-video.mp4` — NutriAlp sesli videosu

## Yerelde açmak

`index.html` dosyasına çift tıklayın; tarayıcıda açılır.

## Yayınlamak (GitHub Pages)

1. Bu klasörü GitHub'da bir depoya yükleyin.
2. Depoda **Settings → Pages** bölümüne gidin.
3. **Source** olarak `Deploy from a branch`, dal olarak `main` ve klasör olarak `/ (root)` seçip kaydedin.
4. Birkaç dakika sonra site `https://<kullanici-adi>.github.io/<depo-adi>/` adresinde yayında olur.
